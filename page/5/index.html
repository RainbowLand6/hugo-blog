目标：按品牌统计商品数量，并掌握几个避免后期返工的 Mapping 原则。

1. 什么是聚合

聚合不是返回每一条商品，而是返回统计结果。例如“每个品牌有多少商品”：

GET /products/_search
{
  "size": 0,
  "aggs": {
    "brand_count": {
      "terms": {
        "field": "brand"
      }
    }
  }
}

size: 0 表示不需要普通搜索结果，只需要统计。

什么是 Kafka

Kafka 是一个用于传递消息的系统。一个程序把消息写进去，另一个或多个程序稍后读出来处理。

拿电商下单举例：用户支付成功后，订单服务不必亲自做库存扣减、发优惠券、发通知。它只需要发送一条“订单已支付”消息；库存、营销、通知等服务各自订阅并处理。这种方式让服务之间不必互相等待。
