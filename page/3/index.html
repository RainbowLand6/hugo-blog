Topic 分区与消息 Key

Topic 分区与消息 Key

目标：理解 Kafka 的并发能力来自哪里，以及哪些消息能够保证顺序。

1. Topic 为什么有分区

一个 Topic 可以拆成多个 Partition：

Topic: order-paid
├── Partition 0: 0, 1, 2, 3 ...
├── Partition 1: 0, 1, 2, 3 ...
└── Partition 2: 0, 1, 2, 3 ...

多个分区能由多个消费者并行处理，提高吞吐量。代价是：Kafka 只保证同一个分区内的消息顺序，不保证整个 Topic 的全局顺序。
